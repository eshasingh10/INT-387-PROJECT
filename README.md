# Population Analysis Dashboard

## Overview

The **Population Analysis Dashboard** is an interactive Power BI project developed to analyze population demographics across **35 States/UTs and 636 districts in India**. The dashboard transforms large demographic datasets into clear, interactive visualizations to identify regional patterns, population distributions, and variations across different geographical levels.

## Key Features

* 📊 Interactive KPI cards for quick population insights
* 🗺️ Map-based visualization for geographical analysis
* 👥 Male vs. female population analysis
* 🏘️ Rural vs. urban household distribution
* 📍 State-level and district-level analysis
* 🏡 Village-level demographic analysis
* 🔎 Interactive slicers and filters for detailed exploration
* 📈 Comparative visualizations for identifying regional patterns

## Dashboard Analysis

The dashboard provides insights into:

* Population distribution across **35 States/UTs**
* Demographic comparison across **636 districts**
* Male and female population distribution
* Rural and urban household percentages
* Village-level population patterns
* Regional variations across different geographical areas

## Dataset

The project uses demographic data covering Indian states, union territories, districts, households, and villages. The dataset enables analysis at both **state and district levels**.

## Project Objective

The main objective of this project is to convert complex demographic data into an **interactive and easy-to-understand analytics dashboard**, enabling users to quickly compare population characteristics across different regions.
